# Ember

面向 FC 爱好者与开发者的模拟器，重点支持小霸王、步步高等学习机。硬件是可替换的模块，卡带上的 mapper 用插件提供：安装 mapper 插件就能增加或更新卡带的电路适配，不用升级整套软件。

设计文档与界面原型已确认；经典 FC（超级玛丽等）与小霸王 2000 学习机（真实 ROM 开机，SB-DOS 与软盘、键盘、鼠标、打印机可用）已能运行，磁带（经典 FC）已可用，软盘文件管理还没有做。

## 特点

- 按真机的结构运行：主机、卡槽、卡带分开，卡带上的 mapper 芯片由插件提供。
- 学习机整机是内置的主机型号（小霸王 97、小霸王 2000、步步高软驱一号、步步高 98、金字塔 PEC-9588、金字塔 PEC-586、686）：在设置里为机型添加 ROM 文件，再从“机器→选择机型”选机型即可开机，ROM 不再当卡带；目前六个机型都可用。
- mapper 以插件安装，程序里不内置任何卡带的 mapper；开发者写好插件就能使用全部硬件模块。
- CPU、PPU、声音、软驱、磁带、键盘、手柄、鼠标等都是独立的硬件模块，每个型号一个模块，软驱、打印机、声音等功能模块各机型共用一份。
- 支持软驱与磁带机：软盘镜像可以在“设备”面板载入、取出、设写保护与保存；磁带机（数据磁带与声像磁带）是独立设备，随时可以载入与取出，经典 FC 开机后可以播放与录音。
- 文件可以直接拖进窗口：NES 卡带直接开机，软盘镜像载入软驱，声音文件载入磁带机。
- 运行中直接管理软盘里的文件：拖入添加、右键删除与改名，学习机立即看到变化，不用反复换镜像（以后再做）。
- 虚拟针式打印机：打印内容自动保存为 PNG 图片，不弹出保存窗口，保存位置在首选项的“打印机”里改。
- 调试服务可开关，通过 TCP 控制模拟器，开发者与 Copilot 不必反复重启模拟器。
- 应用自带帮助文档（“帮助”菜单→“帮助文档”），用系统默认浏览器以网页形式打开，分两类：使用说明、调试接口手册，可搜索。
- 使用 Win32 原生外壳与 C++ 核心，面向 Windows 7 到 Windows 11 的 64 位系统；发布为单个 `Ember.exe`，解压即用，不需要安装。
