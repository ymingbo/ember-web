# 怎么手动新增内置机型

不用改代码、不用重新构建。三步：

## 1. 放 ROM 文件

把 .nes 文件复制到 `roms/` 目录（跟 yuxing.nes 那些放在一起）。

## 2. 在 roms/machines.json 里加一行

用记事本打开 `roms/machines.json`，在数组末尾加：

```json
{
  "file": "你的文件名.nes",
  "label": "下拉框里显示的名字",
  "group": "学习机",
  "desc": "鼠标悬停时的说明（可省略）"
}
```

注意：
- 每个条目之间用逗号隔开，**最后一个条目后面不能有逗号**
- `file` 只写文件名，不要带 `roms/` 前缀
- `group` 决定归到哪个分组：写「学习机」就进学习机组，写别的会新开一组
- 文件必须是 UTF-8 编码，Windows 记事本另存时选「UTF-8」

## 3. 刷新页面

F5 刷新就行，新机型会出现在下拉框里。

---

## 机型不是随便写的

真正的机型由核心按 **mapper 号 + PRG 大小**自动判定，写什么名字都改不了这一点：

| mapper | PRG 大小 | 实际机型 |
|---|---|---|
| 169 | 1MB | 裕兴 |
| 168 | 1MB | 小霸王 SB-97 |
| 171 | 128KB | 步步高 软驱一号 |
| 171 | 512KB | 小霸王 SB-2000 |
| 171 | 2MB | 步步高 98 型 |
| 179 | 512KB | 金字塔 |
| 其它 | — | 普通 FC（走 mapper 插件） |

所以：
- **学习机 ROM** 要能被认成对应机型，mapper 和大小必须对上
- **普通 FC 游戏** 放进 roms/ 也能加进菜单，会走 mapper 插件正常跑

## 如果菜单没变化

1. 检查 `machines.json` 是不是合法 JSON（少逗号、多逗号最常见）
   → 浏览器按 F12 打开控制台，格式错了会看到报错
2. 检查文件名和清单里的 `file` 是否完全一致（大小写敏感）
3. JSON 格式坏了不会白屏 —— 界面会自动退回内置的 6 个机型
